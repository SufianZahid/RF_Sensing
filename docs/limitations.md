# Project Limitations & Model Assumptions

## 1. Overview
This document details the explicit physical approximations, mathematical simplifications, and architectural limitations present across each module of the **Through-Wall RF Sensing Simulator**. 

> [!WARNING]
> **Simulation-to-Reality Gap Warning:**
> This software is a **pure simulation framework**. It relies on simplified 2D ray models and synthetic noise distributions. Models trained on this dataset achieve high accuracy on simulated data, but **their accuracy on real-world RF measurements is unverified and expected to be significantly lower** without transfer learning or domain adaptation.

---

## 2. Module-by-Module Limitations Breakdown

### A. Free-Space & Wall Propagation (`rf_sim/propagation.py`)
- **Isotropic Antenna Assumption:** Transmitters and receivers are modeled as perfect 2D point sources with uniform $360^\circ$ isotropic gain ($0\text{ dBi}$). Physical antennas exhibit non-uniform radiation patterns and polarization losses.
- **No Knife-Edge Diffraction:** Signal propagation assumes straight-line ray geometry. Electromagnetic diffraction around wall edges, door frames, or furniture corners is not computed.
- **Scalar Material Loss:** Wall attenuation is simplified to a single representative attenuation value in dB per material type (e.g., drywall $1.5\text{ dB}$, concrete $12.0\text{ dB}$). Frequency-dependent dispersion, dielectric permittivity, moisture content, and incidence angle reflection variations are omitted.

### B. Human Target Interaction (`rf_sim/human.py`)
- **Point-Scatterer Approximation:** The human target is modeled as an isotropic point scatterer with a scalar radar cross-section (RCS) or reflection loss ($20.0\text{ dB}$). Real human bodies present complex geometry with non-uniform scattering patterns.
- **Flat Occlusion Loss Model:** Line-of-sight (LOS) occlusion is evaluated as a binary ray-segment intersection applying a flat attenuation drop ($10.0\text{ dB}$). Real shadowing varies dynamically based on body posture, chest orientation, and limb positioning.
- **No Micro-Doppler Limb Motion:** The target moves as a single rigid point mass. Biomechanical micro-Doppler signatures caused by swinging arms and walking legs are not modeled.

### C. Multipath & Environment Engine (`rf_sim/multipath.py`)
- **Fixed Clutter Path Count:** Background clutter is synthesized using a small fixed number of static reflection paths (default $N=3$). True indoor environments contain dozens to hundreds of higher-order bounce paths.
- **No 3D Ray Tracing:** Reflections are evaluated strictly in a 2D floorplan plane. Ceiling, floor, and out-of-plane scattering paths are neglected.

### D. Dataset Sampling & Randomization (`rf_sim/dataset_generator.py`)
- **Synthetic Domain Limits:** While scenarios randomize room dimensions ($6 - 12\text{ m}$), wall materials, and node locations, the synthetic distribution cannot capture real-world structural diversity (e.g., HVAC ducting, metallic window frames, dynamic human traffic).

### E. Machine Learning Models (`rf_sim/ml/`)
- **Simulated Data Training:** Models (Random Forest, Logistic Regression, SVM) were trained exclusively on synthetic data generated by `rf_sim`. Consequently, high benchmark accuracies reflect model mastery of the simulator's physical equations rather than guaranteed real-world deployment performance.
